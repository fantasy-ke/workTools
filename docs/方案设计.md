# 方案设计

## 2026-08-04 11:50

### 配置处理工具

#### 目标

在“对比”后、“Cron 工具”前增加“配置处理”菜单，为 API 对接工作提供 Apollo 配置与 JSON 双向转换、固定及自定义分隔符替换能力。所有内容仅在浏览器或 Tauri 本地处理，不上传网络。

#### 菜单与标签

- 新增 `config` 视图，菜单名称为“配置处理”。
- 单击菜单时激活已有配置处理标签；双击时新建独立标签。
- 标签名称使用“配置处理 - 未命名”，不同标签分别保存自己的临时输入和结果，切换时不重建页面。
- 页面采用懒加载，沿用现有动态模块加载恢复机制。

#### 页面布局

- 顶部模式切换：`Apollo ↔ JSON`、`分隔符替换`。
- 工具栏：转换方向或分隔符预设、执行转换、交换或回填、复制结果、清空。
- 主工作区：左右两个 Monaco 编辑器，左侧为输入，右侧为结果。
- 状态区：显示当前规则、解析结果、命中数量或错误信息。
- 编辑器沿用现有主题、字体、自动换行、语法高亮和 `Ctrl+F` 查找能力。

#### Apollo 与 JSON 转换规则

- Apollo 文本支持：`key=value`、`key = value`、逐行配置，以及同一行连续粘贴的多个键值。
- 支持 `:` 和 `.` 两种层级分隔；自动识别输入中使用的层级形式，JSON 反向生成时由下拉框指定，默认使用 `:`。
- 值类型自动识别：整数、小数、布尔值和 `null` 转为对应 JSON 类型；带前导零的数字、无法安全识别的内容保留为字符串。
- 引号包裹的字符串按字符串处理；URL 等普通文本不需要额外引号。
- 重复路径、空键、对象与标量路径冲突会返回明确错误，不覆盖已有值。
- JSON 反向转换时递归展开对象；数组使用紧凑 JSON 表示，避免丢失结构。

#### 分隔符替换规则

- 固定预设包含：逗号转竖线、竖线转逗号、分号转换行、换行转逗号、制表符转逗号、下划线转短横线。
- 提供自定义来源符号和目标符号输入；支持可见文本 `\\n`、`\\t`、`space` 表示换行、制表符和空格。
- 选择预设或自定义规则后，输入编辑器高亮所有来源符号，结果编辑器高亮所有目标符号。
- 显示匹配数量；来源符号为空时禁止执行，未命中时给出提示。

#### 代码组织

- `src/core/configProcessing.ts`：解析、转换、扁平化、替换与高亮位置等纯逻辑。
- `src/pages/ConfigPage.tsx`：页面状态和交互。
- `tests/core/configProcessing.test.ts`：核心转换与异常回归测试。
- `src/App.tsx`、`src/types.ts`：菜单、懒加载、多标签和视图接入。
- `src/i18n/zh-CN.ts`、`src/i18n/en-US.ts`：中英文界面文案。
- `src/App.css`：仅增加配置处理页面所需样式。

#### 验证标准

1. 用户示例可转换为嵌套 JSON，`UseNewOrderWorkPushSign` 为数字 `1`。
2. 生成的 JSON 可以使用 `:` 或 `.` 反向生成为 Apollo 文本。
3. `250_0,268_0,354_0,432_0,370_0,371_0` 使用逗号转竖线后结果正确，并高亮六段之间的五处符号。
4. 单击复用、双击新建、切换标签不丢输入。
5. i18n Key 一致，单元测试、生产构建和 `git diff --check` 通过。
